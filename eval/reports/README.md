## 指標の読み方

### 総合回答成功率

質問単位で、実行、必須要点、回答可能性、根拠支持、重大誤りの5条件をすべて満たした割合です。実行失敗や条件未達を成功として数えません。

### 数値を比較するときの注意

今回の説明では統合220問評価を主結果とします。異なる質問セット、成功規約、モデル、実行条件で得た過去の数値は、この結果に足したり、一続きの精度推移として比較したりしません。個別runの原記録は`eval/results/`以下で確認してください。
