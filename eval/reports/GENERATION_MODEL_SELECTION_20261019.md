# 回答生成モデルの選定記録

- 選定日: 2026-10-19
- 選定モデル: `gemini-3.8-flash`
- 用途: 一回生成の簡易構成における回答生成モデル
- 選定者: ユーザー
- 選定時点の状態: モデル選定済み。2026-10-19時点ではアプリケーション設定への反映は未実施。

## 2026-10-25時点の適用状況

この記録は2026-10-19のモデル選定時点を保持する。後日、別の直接比較とユーザー判断に基づき、一回生成候補がCloud Runへ統合され、2026-10-25にrevision `municipal-rag-assistant-00011-kwv`へdeployされた。公開中の候補generatorは`gemini-3.8-flash`に固定されている。`LLM_MODEL_NAME`のローカル既定値は`gemini-3.1-flash-lite`のままである。deployの根拠は[回答生成経路と公開状態](../../portfolio/04-answer-generation.md)および[GitHub Actions run #172](https://github.com/toko1970/municipal-rag-assistant/actions/runs/40161778266)を参照。

## 1. 比較条件

### 比較対象と入力

比較対象は次の3モデルである。

- `gemini-3.1-flash-lite`（リポジトリの回答生成モデル既定値）
- `gemini-3.8-flash`
- `gemini-3.1-pro-preview`

モデルの効果だけを比べるため、質問文と根拠文書を固定して全モデルへ同じ入力を渡した。根拠文書は、実務経験者承認済み90問評価ブックから抽出したケースごとの提示文書であり、このモデル比較中にベクトル検索は実行していない。検索結果の差を回答生成モデルの差へ混ぜないためのcontext-fixed評価である。

### 回答生成までの経路

```text
評価ケースの質問文 + 固定済み根拠文書
              ↓
既存の自然文プロンプト（src.rag_chain.build_prompt）
              ↓
対象モデルを1回呼び出し
              ↓
「回答分類・回答・根拠文書」を含むテキスト出力
```

質問意図の事前構造化、根拠文書の要素解析、v1の回答JSON Schema、独立した分類器による後段判定は使用していない。モデルは回答本文と分類ラベルを同じ呼び出しで生成し、評価ではその出力本文を採点した。したがって、ここでの自動分類ラベル一致率は補助指標であり、本番の独立分類器の性能を示すものではない。

### 固定した実行条件

| 条件 | 内容 |
|---|---|
| Provider | Gemini Developer API |
| Temperature | 0 |
| 最大出力 | 1,024 tokens |
| 試行 | 1ケース・1モデルあたり1回。test確認時の再試行なし |
| prompt | `src.rag_chain.build_prompt`、全候補で同一 |
| 採点 | 承認済み評価ブックの基準に沿った回答本文の手動採点 |
| goldの扱い | 質問・根拠と期待判定を分離し、モデル応答取得後に採点へ使用 |

## 2. 比較した指標

主指標は、回答可能なA1ケースでは根拠付き回答成功（M3）、保留対象のA2/A3ケースでは適切な保留対応成功（M4）を満たした件数を合算した総合回答成功率である。

誤りの性質を分けるため、次の指標も比較した。

- M1: 保留対象に対する不適切な回答
- M2: 回答可能ケースに対する不要な保留
- G1: 重大誤り
- Q1〜Q4: 回答／保留判断、理由、次の対応、回答内容と根拠の観点
- 自動生成された回答分類ラベルの一致率（補助指標）
- REVIEW_REQUIRED、APIエラー
- API費用推定、平均応答時間、p95応答時間
- scenario group単位のペア比較

分類ラベルの一致率だけで回答品質を代表させず、回答本文を主に評価した。

| 指標 | Flash-Lite | Flash | Pro |

| 総合回答成功 | **35/46 (76.1%)** | 34/46 (73.9%) | 30/46 (65.2%) |
| A1 根拠付き回答成功 M3 | 34/35 (97.1%) | 33/35 (94.3%) | 30/35 (85.7%) |
| A2/A3 適切な保留対応 M4 | 1/10 (10.0%) | 1/10 (10.0%) | 0/10 (0%) |
| 保留対象への不適切な回答 M1 | 4/10 (40.0%) | **1/10 (10.0%)** | **1/10 (10.0%)** |
| 重大誤り G1 | 4/46 (8.7%) | **1/46 (2.2%)** | **1/46 (2.2%)** |
| 自動回答ラベル一致（参考） | 41/46 (89.1%) | 44/46 (95.7%) | 45/46 (97.8%) |

開発用分割ではFlash-Liteの総合成功がFlashを1件上回った。一方、Flashは保留対象への不適切な回答とG1が少なかった。Proは総合成功、費用、応答時間のいずれでも選定優位を示さなかった。

ユーザーのレビューに基づき、Flashの次の3ケースを成功として再採点した。

| ケース | 反映したレビュー | 再採点 |
|---|---|---|
| X014-T0 | DOC-002の通勤条件はすべて満たす必要があり、通勤手段の記載がないためFlashの確認保留を誤答とは言えない | Flashの成功として加算。不要保留M2から除外 |
| X014-T1 | Flashも不足情報の確認を促しており、次対応を不適切とは言えない | Flashの適切な保留対応M4として加算 |
| X026-T0 | 質問は契約名義の原則を尋ねており、Flashは原則を過不足なく回答している | Flashの根拠付き回答成功M3として加算 |

この再採点でFlashの総合成功は初回32件から35件へ、成功scenario groupは13群から14群へ変わった。Flash-Lite側の件数は変更していない。X014-T0についてDOC-002の条件を完全に満たすかを厳密に問う場合、Flash-Lite回答の通勤手段条件への言及不足も別途レビュー対象となるため、ここではユーザーの指示どおりFlash側の評価だけを変更した。

再採点後もFlash-Liteの総合成功はFlashより2件多く、費用は約10.8倍低く、平均応答時間は約5.5倍短い。一方、Flashは保留対象への不適切な回答が1件少なく、G1も初回採点では1件少なかった。scenario group単位ではFlashが14/22、Flash-Liteが15/22で成功した。

## 追加原票照合と対称再集計（2026-10-25）

ローカルの90件実務者レビュー用ブックと44件比較原票を照合した。ブックはmanifest記録のSHA-256と一致し、90/90ケースの承認および別runの回答90/90件の実務者採点が確認できた。一方、44件比較の初回88判定はすべて`human_reviewed=false`で、Codexのrubric reviewとして記録されている。90件と44件は別runであり、レビュー件数を合算しない。

このセッションでユーザーがX014-T0/T1およびX026-T0/T3の規約を明示し、両モデルへ対称適用した補足集計はFlash 36/44、Flash-Lite 37/44。paired groupは両方成功13、Flashのみ2、Flash-Liteのみ2、両方失敗5。内訳・期待値変更・REVIEW_REQUIREDの扱いは[追加採点記録](../results/model_tier_test_confirmation_20261019/supplemental_adjudication_20261025.md)に記載する。元回答、初回judgments、metricsは保持した。残りの判定はCodexの初回採点のままであり、88回答すべてを新たに実務者が再審査した結果ではない。

## 4. 採用モデルと選定理由

**採用モデルを`gemini-3.8-flash`とする。**ユーザーは安全性を優先して同モデルを選定した。2026-10-25の追加原票照合・対称再集計では、Flash-Liteの総合成功は37/44、Flashは36/44で、Flash-Liteが1件上回る。FlashのM1は0/11、G1は0/42で、Flash-LiteのM1 2/12、G1 2/44より少ない。Flash-Liteは費用と応答時間で優位。総合成功率・運用効率の低下を受け入れ、安全性を重視した選択である。補足集計の限界は[追加採点記録](../results/model_tier_test_confirmation_20261019/supplemental_adjudication_20261025.md)を参照。

この選定は、評価セット上でFlashが全体として高精度、または安全性が十分であることを意味しない。Flashには2件のREVIEW_REQUIRED出力があり、Flash-Liteには2件のG1が残る。44件の補足採点は既存Codex判定を保持した限定的な対称再集計である。モデル選定とアプリ設定変更は別であり、この記録作成によって`LLM_MODEL_NAME`は変更していない。

### レビュー上の留意点

35/44という記載は、10月19日時点のFlash側だけへの限定訂正を示す履歴値である。10月25日に4ケースの解釈をユーザーが明示し、両モデルへ対称適用した結果はFlash 36/44、Flash-Lite 37/44。原回答・初回judgments・metricsは監査用に保持し、補足採点を別ファイルに記録した。

X026-T3は初回採点で両モデルにG1が付いた。2026-10-25にユーザーが一般原則の質問としてA1回答可能と裁定し、両モデルの原則回答を成功・G1なしへ補足変更した。初回採点の原票は変更していない。

今回開封した44件のテスト分割は、今後の候補調整や新しいモデル選定には再利用しない。将来の変更確認には別の未使用データを用いる。
