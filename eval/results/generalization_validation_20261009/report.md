# 期限回答指示の開発 challenge 検証（2026-10-09）

**判定：この1文の指示追加は採用候補へ進めない。** 現行設定の Gemini 3.1 Flash-Lite では、うるう年の1表現で旧指示が正しかった期限を候補が1日誤った。別モデルの Gemini 3.5 Flash-Lite でも候補が年越し期限を1年、うるう年期限を1日誤って断定した。根拠外claimの新規発生0件という[採用判定プロトコル](../../INTERVENTION_ADOPTION_PROTOCOL.md)の Gate 4 に抵触する。これは開発 challenge の早期失格判断であり、24シナリオ全体の成功率や汎化改善率を推定した結果ではない。

## 固定した比較

候補は現行の生成用 base prompt 先頭へ「期限を回答するときは、具体的な年月日と時刻まで答えてください。」を1文追加するだけ。旧指示と候補は同じ質問、根拠、answer-output-v1 schema、temperature 0、seed 42、出力上限1024、各モデル内の設定を使用した。検索、分類、表示を通す比較ではない。

[作成担当の点検](fixture_review.md)済みの開発用未知 challenge は24シナリオ×2表現、6架空制度。19シナリオは具体期限を求め、5シナリオは条件不足で一意な期限を断定してはならない。採点用 `gold`・`review_note` をpromptへ混ぜず、`question` と `evidence` のみをallowlistで入力した。fixture SHA-256は `67fdfc876ccfb1489a570b8437b524fbee484cf02bbcee2cd40cf687ab5896dd`。

初回の[事前manifest](manifest.json)は120呼出し（48表現×旧・候補＋6シナリオ×2表現×旧・候補の反復）、推定費用上限0.30 USD、再試行0を固定した。主指標は「2表現とも意味上正しい」シナリオ単位のpaired成功。次段階へ進む条件は正味3シナリオ以上の改善、回答可能例の新規シナリオ退行0、条件不足5例の新規危険断定0、全表現の有効かつ根拠に支持される出力である。正解の日付文字列を含むだけでは合格させず、全出力の書類・期限対応、矛盾、余計な期限、引用、未規定時刻、不要な確認を本文確認した。`semantic_review.jsonl` は機械的な文字列検出と区別する。

## 停止・モデル変更の扱い

3.1と3.5はfree-tierの**毎分15件**、2.5は**毎分5件**のモデル別枠へ達し429となった。日次・総量枯渇ではない。3.1は16件目、2.5は8件目、3.5は17件目で、各runnerの事前固定した「quota errorで停止」に従い止めた。2.5の503は事前固定した再試行0のため未生成として残した。120件を完走したモデルはない。

当初のmanifestに「安全gate不合格なら途中で全challengeを打ち切る」という明示的な逐次停止規則はない。モデル変更は429後に判断し、変更先ごとに[2.5の事前manifest](../generalization_validation_20261009_gemini25/manifest.json)、[3.5の事前manifest](../generalization_validation_20261009_gemini35/manifest.json)と120件の全タスクを別途固定して最初から開始した。各モデルの応答を混ぜてpaired集計していない。2モデルでも新規誤期限が観測された後、Gate 4 不合格候補を追加費用と時間を使って全量実行しない判断は**結果を見た後の早期停止**である。したがって候補が一般に何件改善するか、6制度間の差、モデル間の優劣、安定性はこのデータから主張しない。レビューが全量実行を必要と判断した場合は、別の事前固定計画と毎分枠に収まる間隔で再実行する。

## 方針に照らした到達範囲

固定根拠で生成層の単独変更を比較し、未知の条件・言い換えの一部で旧のみ成功、候補のみ成功、新規誤期限を観測した。評価順序がD01から始まるため、観測は1制度の初期4シナリオへ偏る。事前固定した6シナリオ反復の区間には到達していない。scenario単位bootstrapや制度単位のばらつきはこの停止データでは算出しない。

期限候補の Gate 2/4 が不合格なので、既存100表現・130問の新規回帰、代表分布、検索から表示までの一連の処理、独立した制度群のsealed holdoutは実施していない。分類の自動対象抽出・2軸判断・最終表示はこのprompt候補の作用層外であり、[準備状況](classification_and_display_readiness.md)のローカル49テスト合格を実モデルの未知制度汎化成功とみなさない。難しい分類境界の新goldはユーザー確認を経ていないため、今回の採用判定には入れていない。表示回復の実モデル入力・正常対照についても新規実行はない。したがって[汎化検証方針](../../GENERALIZATION_VALIDATION_PLAN.md)全体の完了は主張できない。
