# Required facets生成promptの小規模比較

## 目的

評価セットv1.2の残存失敗は、回答生成6件、回答分類4件、検索3件だった。回答生成のうち
テキスト4件に共通して見えた「質問の必須項目を先に固定しない」問題へ、Schemaを変えない
最小のprompt変更を試した。

本番promptを先に変更せず、保存済み検索結果を固定した小pilotで改善と退行を測る。図表2件は、
過去の同種prompt比較で正常例が退行しているため対象外とした。

## 実行条件

- 失敗対象: Q066、Q131、Q386、Q391
- control: Q166、Q206、Q421、Q431、Q441、Q446
- baseline: 保存済み`answer-claims-v1`出力
- candidate: `answer-claims-required-facets-v1`
- Generator / Classifier: `gemini-3.1-flash-lite`
- 検索結果: baselineのelement IDと順位を固定
- 最大logical external calls: 20
- 実使用: 20
- retry: 0
- 費用上限: US$0.04
- 実測費用: US$0.01053975
- sealed holdout: 未使用

採用gateは、失敗4件中2件以上改善、control退行0、根拠外・質問外claim増加0とした。

## 結果

| 指標 | 結果 |
|---|---:|
| 厳密gateで改善した失敗 | 0 / 4 |
| 人手で意味上の改善を確認 | 1 / 4（Q391） |
| 退行したcontrol | 4 / 6 |
| pipeline error | 3 / 10 |
| 採用判定 | **不採用** |

Q391は、マニュアルの「受付不可」とFAQの「書類が揃うまで認定未完了」を両方示し、優先関係を
人事給与課へ確認する回答になった。自動基準の`受付できません`に対して出力が`受付できない`
だったため厳密gateには入らない。表記差を意味上の成功として扱っても改善は1件で、採用条件の
2件へ届かない。評価後に基準を書き換えて採用結果を変えない。

## 失敗対象の観測

| ID | 観測結果 |
|---|---|
| Q066 | 判断要へ変わったが、根拠で支持される「翌月以降の場合がある」というclaim自体を落とした |
| Q131 | 距離と届出期限は維持したが、一時的変更かという質問外の不足条件と版競合を作った |
| Q386 | 個別確認は追加したが、質問外の「書類不備なら受付不可」を残し、表示契約errorになった |
| Q391 | 根拠の不一致と確認先を明示し、意味上は改善した |

## control退行の観測

- Q421: 改定前後を尋ねる比較質問を版競合と誤判定した。
- Q431: 質問されていない届出遅延等を不足条件へ追加し、根拠十分の表示契約と衝突した。
- Q441: 質問されていない返納判断基準と提出遅延を不足条件へ追加し、表示契約と衝突した。
- Q446: 本人名義という必須facetを落とし、適用日が明示されているのに旧版との確認を要求した。

## 判断

候補promptを本番へ反映せず、130問回帰も実行しない。質問facetの内部確認を自然言語で一律に
強めると、未質問事項まで「不足条件」に広げる傾向が出た。回答生成6件は件数上最大だが、
項目欠落、質問外claim、根拠衝突、図表適用境界を含む異質な集合であり、一つのpromptで安全に
直せる最大原因ではなかった。

次に回答生成へ戻る場合は、同じpromptの言い換えを繰り返さない。次のいずれかを独立した
experimentとして扱う。

1. facetをSchemaへ明示し、claim・不足条件との対応をcodeで検証する。
2. 根拠衝突を検出した場合だけ専用処理へ送り、全質問を判断要へ寄せない。
3. 質問外claimを検出するalignment validatorを、観測済み類型へ限定して試す。

ただし、いずれも追加Schema、処理分岐、または外部callを要する。最小作業で総合回答成功率を
上げる観点では、次は同じ原因でまとまっている検索失敗3件のHybrid Search / reranking比較を
優先する。

## 再現方法

```bash
.venv/bin/python -m eval.compare_generation_facets_prompt \
  --output-dir eval/results/generation_facets_prompt_comparison_v1 \
  --max-logical-external-calls 20 \
  --max-cost-usd 0.04
```

既存出力は上書きしないため、再実行時は新しい出力先を指定する。
