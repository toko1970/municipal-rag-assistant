# 難問セットによる回答品質と失敗原因の評価

2026-09-23に、[evaluation_questions_hard.csv](evaluation_questions_hard.csv) の20件を対象として、公開アプリと同じベクトル検索と回答生成を実行しました。検索だけを測定した[難問検索評価](HARD_EVALUATION.md)に続き、回答分類、回答内容、根拠のない生成を質問単位で確認する評価です。

## 評価方法

- 検索方式：Chromaによるベクトル類似検索、上位5チャンク
- Embedding：`gemini-embedding-001`
- 回答生成：`gemini-2.5-flash`、temperature 0
- 質問セット：複数文書5件、文書に答えがない質問5件、言い換え・誤字5件、似ているが答えの異なる質問5件
- 分類一致：出力された「根拠十分／判断要／文書不足」と、事前に固定した期待分類を自動比較
- 内容妥当性：回答を[人手確認基準](hard_answer_review_criteria.csv)と照合
- 幻覚抑制：取得した根拠または対象文書で支持されない断定がないか人手確認

内容妥当性と幻覚抑制は、LLMによる自動採点を正解として扱わず、人手で判定しました。質問、期待分類、判定基準は回答生成前に固定しています。

## 実行結果

20件中19件は回答生成まで完了しました。H20はGemini無料枠の日次リクエスト上限により回答生成に失敗したため、精度の分母から除外し、回答生成エラーとして残しています。

| 指標 | 結果 |
| --- | ---: |
| 回答分類一致 | 10/19（52.6%） |
| 内容妥当性 | 12/19（63.2%） |
| 幻覚抑制 | 18/19（94.7%） |
| 分類・内容・幻覚抑制をすべて満たした | 9/19（47.4%） |
| 回答生成エラー | 1/20 |

成功した19件の検索開始から回答完了までの時間は、平均5.58秒、中央値4.68秒、最短2.47秒、最長16.50秒でした。これはローカルでの1回の測定であり、ネットワーク変動を含みます。APIの金額とトークン数は取得していないため、この結果から費用は算出していません。

## 失敗原因

APIエラーを除く19件のうち、分類・内容・幻覚抑制をすべて満たした5件と、文書に答えがないことを適切に扱った4件を成功としました。残る10件を排他的に分類しました。

| 原因 | 件数 | 質問ID |
| --- | ---: | --- |
| 検索失敗 | 5 | H01、H03、H04、H12、H17 |
| 回答分類失敗 | 3 | H14、H16、H18 |
| 回答生成失敗 | 1 | H15 |
| 文書に根拠がない質問への対応失敗 | 1 | H09 |

### 検索失敗

H01、H03、H04、H12、H17は、回答に必要な見出しが上位5件に揃いませんでした。例えばH12とH17は、届出の種類を取得できても「提出期限」の節が上位5件に入らず、具体的な日数を回答できませんでした。H03では旧ルールの「翌月から支給」を取得し、優先すべき改正後の「認定月から支給」を取得できなかったため、誤った開始時期を回答しました。

### 回答分類失敗

H14、H16、H18は、回答内容は人手確認基準を満たしましたが、期待した「判断要」ではなく「根拠十分」と分類しました。必要な根拠を取得できても、個別確認や詳細条件が残るケースを分類へ正しく反映できていません。

### 回答生成失敗

H15は改正後の家賃条件が「15,000円を超える」であるところを「下限は15,000円」と回答しました。必要な根拠は取得できていますが、境界値を含む表現が不正確でした。

### 文書に根拠がない質問への対応失敗

H09の会計年度任用職員について、対象文書は別規程によると明記しています。モデルは具体的な給料日を断定しなかったものの、適用対象の記載がないと誤って説明し、「文書不足」ではなく「判断要」と分類しました。

## 再実行方法

回答生成には`GOOGLE_API_KEY`が必要です。API上限で一部だけ失敗した場合は、`--question-id`で対象を限定できます。

```bash
python -m eval.evaluate_answer_quality \
  --input eval/evaluation_questions_hard.csv \
  --output eval/results/hard_answer_quality.csv

python -m eval.evaluate_answer_quality \
  --input eval/evaluation_questions_hard.csv \
  --output /tmp/h20-answer.csv \
  --question-id H20 \
  --delay-seconds 0
```

内容妥当性と幻覚抑制を人手確認した後、検索結果と結合して失敗原因を集計します。

```bash
python -m eval.summarize_rag_failures \
  --answers eval/results/hard_answer_quality.csv \
  --retrieval eval/results/hard_baseline.csv \
  --output eval/results/hard_failure_analysis.csv
```

## 現時点の判断

完了した回答の失敗10件中5件が検索失敗であり、今回の4分類では検索が最大原因でした。一方、検索に成功した質問にも回答分類3件、回答生成1件の失敗があります。次の改善では、検索方式を直ちに変更する前に、判断要の条件を回答分類へ反映する方法か、複数の論点を分けて検索する方法を1つ選び、同じ20件で再評価します。
