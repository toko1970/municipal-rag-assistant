# 質問・回答画面

[機能一覧へ](README.md) · [トップの構成図へ](../README.md#アーキテクチャ)

制度や手続きについて質問すると、回答、回答区分、参照した根拠本文と文書情報を確認できます。図表が根拠に含まれる場合は、元ページ画像も表示します。回答へのfeedbackも送れます。

回答だけを見せるのではなく、根拠と出典の版を同じ画面で確かめられることを重視しています。根拠が足りない場合や個別判断が必要な場合も、回答区分で示します。

- 図表表示と評価: [図表RAGの実装状況](../eval/reports/VISUAL_RAG_STATUS.md)
