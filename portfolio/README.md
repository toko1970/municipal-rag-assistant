## 全体のデータの流れ

文書は検索できる単位に整理し、PostgreSQLに正本、Qdrantに検索indexを保存します。利用者の質問はQdrantから根拠を取得し、回答・回答区分とともに画面へ返します。検索結果や回答の記録はPostgreSQLに関連付けて保存します。

図表を含む文書では、レビュー済みの抽出内容を登録し、参照時にページ画像も表示します。任意PDFのアップロードとレビューを行うWeb管理画面はありません。
